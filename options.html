Reply wait threshold

Before this time the ticket stays Waiting. After it, a Missed notification fires; if the agent takes longer than this to reply, a Late warning shows. 1-168 hours, default 12.

Assigned ticket reminder

Normal/Low use the setting above; High defaults to 5 minutes and Urgent to 1 minute. Alerts once per customer message while the ticket is assigned to you. Requires the agent name to be detected from your My tickets scan.

Daily summary

Send a daily activity summary notification
Includes today's customer replies and agent replies, currently unanswered tickets, and average recorded response time. Default: every day at 9:00 AM.
