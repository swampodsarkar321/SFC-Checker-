QUICK SETUPপ্রায় ৩ মিনিট
  1. 01

    ZIP download করে Extract করুন

    Download বাটনে চাপুন। Downloads folder-এ ZIP-এর ওপর right-click করে Extract All… নির্বাচন করুন।

    ✅ Extract করার পর folder-এ manifest.json দেখা যাবে।
  2. 02

    আপনার browser-এর Extensions page খুলুন

    নিচের ঠিকানাটি browser-এর address bar-এ লিখে Enter চাপুন।

    CGoogle Chromechrome://extensions
    EMicrosoft Edgeedge://extensions
  3. 03

    Developer mode চালু করুন

    Extensions page-এর উপরের ডান পাশে থাকা Developer mode toggle On করুন। এরপর নতুন action button দেখা যাবে।

  4. 04

    Extract করা extension folder load করুন

    Load unpacked চাপুন → Extract করা folder-টি select করুন → Select Folder চাপুন। ZIP file বা তার বাইরের Downloads folder select করবেন না।

    📁 সঠিক folder খুললে তার ভেতরেই manifest.json থাকবে।
  5. 05

    Packzy-তে যান, Deep Scan চালান

    Packzy Support খুলুন → My tickets / Mine নির্বাচন করুন → extension icon চাপুন → Deep Scan চালান।

    Scan শেষ হলে agent name detect হবে এবং ticket dashboard-এ দেখাবে। Notification চাইলে browser-এর permission-এ Allow দিন।

হয়ে গেছে!Extension চালু আছে। Packzy tab-এ icon চাপলে tracker panel খুলবে।

Install-এ সমস্যা হচ্ছে?
  • “Manifest file is missing” — ZIP extract করে এমন folder select করুন, যেটির ভেতরে manifest.json আছে।
  • Extension icon দেখাচ্ছে না — Extensions icon থেকে SFC TICKET CHECKER pin করুন; তারপর Packzy Support tab-এ যান।
  • নতুন version install — আগে Options → Backup থেকে data export করুন। তারপর নতুন ZIP extract করে Extensions page-এ Reload বা নতুন folder load করুন।

ডেটা ও leaderboard সম্পর্কে

Leaderboard-এ agent name, rating, satisfaction percentage ও tracked ticket count দেখানো হয়। Ranking-এ rating প্রথমে, সমান হলে satisfaction percentage এবং এরপর ticket count বিবেচনা করা হয়। Extension-এর ticket/scan data Firebase-এ আপনার আলাদা account path-এ sync হয়। Firebase access project-এর published security rules-এর ওপর নির্ভরশীল। Firebase configuration error দেখালে extension administrator-এর সঙ্গে যোগাযোগ করুন।

সাহায্য

সাধারণ প্রশ্ন

ZIP download করলেই কি extension install হবে?

না। ZIP extract করে Extensions page-এ Developer mode চালু করতে হবে, তারপর Load unpacked দিয়ে যে folder-এর ভেতরে manifest.json আছে সেটি নির্বাচন করুন।

আমাকে কি Firebase URL বা agent name দিতে হবে?

Firebase URL extension-এ আগে থেকেই সেট করা। My tickets/Mine scope-এ Deep Scan চালালে agent name স্বয়ংক্রিয়ভাবে detect হয়।

নতুন version এলে কীভাবে update করব?

আগে Options → Backup থেকে data export করুন। নতুন ZIP download ও extract করে Extensions page-এ extension Reload করুন; নতুন folder হলে Load unpacked দিয়ে সেটি load করুন।

Extension কি শুধু এক tab-এ scan চালায়?

হ্যাঁ। যে Packzy tab থেকে Deep Scan শুরু করবেন, scan সেখানেই চলবে। Scan শেষ না হওয়া পর্যন্ত অন্য Packzy tab-এর quick scan কোনো ticket খুলবে না, তাই চলমান scan-এর ticket selection বদলাবে না।
